# Contributing

Thank you for considering a contribution.

## Development

1. Fork the repository.
2. Create a branch: `git checkout -b feature/clear-name`.
3. Run `npm test`.
4. Make one focused change.
5. Add or update tests.
6. Open a pull request explaining the problem and the solution.

## Good first issues

- add fixtures for real WordPress themes
- improve malformed HTML handling
- add French output
- add a Markdown report format
- document n8n integration
- expand JSON-LD test cases

Please do not include private API keys, copyrighted article text, or personal data in issues or fixtures.
